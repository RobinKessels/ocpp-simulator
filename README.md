# OCPP 1.6 Charger & CSMS Simulator

A containerized Python-based simulator for EV Charging Stations (Charge Points) and a Central System (CSMS) using the **OCPP 1.6J** protocol.

## 🛠 Setup & Running

Ensure you have [Docker](https://www.docker.com/) and [Docker Compose](https://docs.docker.com/compose/) installed.

`docker-compose up --build`
